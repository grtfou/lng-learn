# 拾語 · lng-learn

在本機瀏覽器使用的單人語言學習工具。目標是以口說建立豐富單字卡，並透過主動回想與 FSRS 間隔複習維持記憶。

**目前完成 P0 骨架與 P1.1 正式字典／詞義／逐欄來源切片，尚未完成整個 MVP。** 建議接手 AI 先閱讀 [AGENTS.md](AGENTS.md)、[實作計畫](docs/PLAN.md)、[架構決策](docs/ARCHITECTURE.md)，再依 [交接清單](docs/HANDOFF.md) 進行下一步。

## 快速開始

需求：**Node.js 24.14 以上的 24.x 版本**（本次驗證為 24.19.0）、**pnpm 11.25.0**。Node 版本可依 `.node-version` 安裝；pnpm 安裝方式見 [官方文件](https://pnpm.io/installation)。由專案根目錄執行：

```sh
pnpm install --frozen-lockfile
cp .env.example .env
pnpm dev
```

開啟 [http://127.0.0.1:5173](http://127.0.0.1:5173)。API 在 `127.0.0.1:3001`，資料自動寫入 `data/lng-learn.sqlite`。不用註冊帳號、不需要任何 API key。首次畫面沒有預先建立的單字庫與單字。

1. 建立單字庫，例如「日常英語」。
2. 輸入 `apple`、`bank` 等英文字，按「產生預覽」才即時查詢網路字典。
3. 明確選一個英文義項，填寫確認過的繁中釋義，校閱後儲存。若無網路，內容來源可改選手動或內建示範。
4. 選「開始複習」→ 先回想 → 顯示答案 → 誠實評分。
5. 到期時間與複習紀錄保存於 SQLite，重開程式仍保留。

語音辨識需支援的瀏覽器、麥克風權限，以及先勾選介面的語音同意選項。可選唸單字或逐字母拼讀。辨識結果一定可以修正；不支援的瀏覽器仍可文字輸入。

## 指令

```sh
pnpm typecheck  # 全部 TypeScript 型別檢查
pnpm test       # 排程、持久化、交易、HTTP 契約、拼讀與 UI 競態／重試測試
pnpm build      # 編譯前端與伺服器
pnpm start      # 建置後的單一程序，含靜態前端
pnpm check      # 型別、測試與建置
```

正式建置模式開啟 [http://127.0.0.1:3001](http://127.0.0.1:3001)。所有指令請在根目錄執行。開發模式固定前端 5173，API 預設 3001；若更動 `PORT`，需同步更改 `apps/web/vite.config.ts` 的代理埠。未實作 PWA 或背景通知，程式關閉期間不發提醒，重開後依已保存的時間計算到期佇列。

預設 `CONTENT_PROVIDER=free-dictionary`，啟動不預抓資料，只有按「產生預覽」才查詢當次輸入的詞。若既有 `.env` 仍設為 demo，可改成以下設定後重啟：

```dotenv
CONTENT_PROVIDER=free-dictionary
```

使用 [Free Dictionary API v2](https://dictionaryapi.dev/)，免帳號與 API key；只將查詢字送至字典服務，不傳送錄音。輸入 `apple` 或 `bank`，先選英文義項，再填繁中釋義並確認儲存。口音、個別作者與錄音者若未提供會明列未知；音檔尚未下載／播放。逐欄來源可展開檢查原址、授權、取得時間與人工修改旗標，詳見 [來源決策](docs/DICTIONARY.md)。

「內容來源」可隨時選內建示範或直接手動建卡，兩者不查詢網路。正式字典查無資料、離線、10 秒逾時、限流或格式錯誤時仍能手動保存；同字重查保留已編輯草稿，429 依 Retry-After 等待。切換詞義會保留人工文字，儲存前請確認釋義與新義項相符。改詞形會清除舊義項與未修改的自動教材；切換內容來源只保留人工修改，其餘使用新來源。重查缺少舊義項時會明列保留的原選項，避免選單與保存不一致。刷新後恢復草稿仍屬 P1.3。

不預載完整字典或音檔，也不預建單字庫；測試 fixture 僅在 tests/，不打包到正式產物。保留的三個小型 demo 為明確選擇的示範入口；一般使用仍即時查詢。後續音檔下載／播放也應按需取得，保存已確認素材的快取屬 P1.2。

`DATABASE_PATH` 可改存放位置。既有 v1 資料首次啟動會先產生 `<DATABASE_PATH>.pre-v2-<uuid>.sqlite` 一致性備份，再遷移詞義與來源；原內容、卡片、排程與 logs 保留。遷移錯誤會回滾並停止啟動，請保留原檔與備份。舊 demo 內容維持示範標籤，逐欄來源標 legacy；無義項的手動／demo／legacy 同詞仍去重。`.env` 與 `data/` 不納入 Git。其他 CONTENT_PROVIDER 值會拒絕啟動。


## 資料與操作範圍

伺服器只綁定 `127.0.0.1`，沒有多帳號與雲端同步。基本 Host／Origin 限制不等於對其他本機程式的存取隔離；此架構依單人、可信任本機環境設計。請勿直接改為公開網路服務。

目前沒有備份 UI。手動備份前先停止伺服器，再複製完整 `data/` 目錄；SQLite 使用 WAL，運行中只複製 `.sqlite` 可能漏資料。完整備份、匯入與資料復原驗證列於 P1。
