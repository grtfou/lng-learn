## 瀏覽器實際操作

使用 Codex 內建瀏覽器，含窄版畫面。

- 空白資料起始，建立「日常英語」。
- 以 `journey` 產生 demo 預覽，確認畫面明列非即時查詢。
- 修改釋義後儲存，列表顯示修改內容，輸入欄清空。
- 進入複習，正面不展示釋義或評分；揭示答案後才出現四評分。
- 按「記得」，成功保存評分、待複習數減為 0、顯示下次到期時間。
- 重開 server，原單字、人工修改與尚未到期排程皆保留。
- 在窄版使用新增入口建立第二庫「旅行路上」，可在兩庫切換。
- 輸入沒有 fixture 的 `serendipity`，介面提示手動輸入，釋義空白時無法儲存。
- 填寫釋義後儲存，標示手動內容且不捏造音標；焦點回到新單字輸入欄。

測試期間發現並修正：tsup 改寫 `node:sqlite` 匯入導致正式產物無法啟動；窄版新增單字庫入口被隱藏；儲存時焦點嘗試發生於輸入仍 disabled 的時間點。

### 外部驗證與限制

- 真實服務只手動查詢免費字典 apple／bank；另以 Node fetch 保存 bank 四詞條原始 JSON 作固定快照。早期 curl 回 HTML 404／530，之後正式建置查詢成功；不能因此保證上游可用性。
- 正式服務未強制製造 429 或逾時，這些用固定回應與注入時間測試；瀏覽器實際觀察的是一次格式錯誤及恢復保稿。
- 字典不提供可信繁中翻譯；釋義由人填寫，不宣稱翻譯品質經自動驗證。sense key 隨上游英文 gloss 改寫而改變，無跨版本義項比對。
- 錄音只有 metadata，沒有音檔快取或播放；沒有開啟麥克風或播放系統發音，不宣稱硬體／母語人士錄音驗證通過。
- 尚無背景工作、跨刷新草稿保存、其他內容 providers、備份 UI／匯入匯出、已存內容編輯／刪除、每日限額與撤銷評分；依 P1.2 以後施工。
- 僅使用 Codex 內建瀏覽器，尚未全面驗證 Chrome／Safari／Firefox、螢幕閱讀器與所有鍵盤路徑。
