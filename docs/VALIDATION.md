## 瀏覽器實際操作

使用 Codex 內建瀏覽器，含窄版畫面。

- 空白資料起始，建立「日常英語」。
- 以 `journey` 產生 demo 預覽，確認畫面明列非即時查詢。
- 修改釋義後儲存，列表顯示修改內容，輸入欄清空。
- 進入複習，正面不展示釋義或評分；揭示答案後才出現四評分。
- 按「記得」，成功保存評分、待複習數減為 0、顯示下次到期時間。
- 重開 server，原單字、人工修改與尚未到期排程皆保留。
- 在窄版使用新增入口建立第二庫「旅行路上」，可在兩庫切換。
- 輸入沒有 fixture 的 `serendipity`，介面提示手動輸入，釋義空白時無法儲存。
- 填寫釋義後儲存，標示手動內容且不捏造音標；焦點回到新單字輸入欄。

測試期間發現並修正：tsup 改寫 `node:sqlite` 匯入導致正式產物無法啟動；窄版新增單字庫入口被隱藏；儲存時焦點嘗試發生於輸入仍 disabled 的時間點。

## 尚未驗證與產品限制

- 沒有啟用真實麥克風、授予麥克風權限或傳送錄音，不能宣稱實機語音辨識已驗證。
- 未播放系統聲音；TTS 的聲線、音量、語言套件與可能的遠端服務需在使用者裝置驗證。
- 未逐一驗證 Chrome、Safari、Firefox 的相容性，未進行完整鍵盤與螢幕閱讀器稽核。
- 正式字典、圖片、真人音檔、例句來源及 LLM provider 尚未實作，沒有外部服務串接或授權資料驗證結果。
- 備份／復原、匯入匯出、已存內容編輯／刪除、草稿恢復、每日限額、參數最佳化屬後續工作。
- 大型單字庫壓力測試尚未進行；P0 單字列表無分頁、複習每批最多 100 張。
- 介面互動有手動瀏覽器驗證與 happy-dom 元件測試，尚未納入可重跑的真實瀏覽器端對端測試。

本紀錄只表示基本架構與上述流程可用，並非完整 MVP 完成。
